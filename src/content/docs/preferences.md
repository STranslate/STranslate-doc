软件设置页面右上角提供查找框。输入内容后会弹出相关建议，点击建议项即可跳转到具体设置。

## 语音朗读

可以通过 Microsoft Edge TTS 等语音服务朗读文本，调整语速和音调，用于听力练习。更多服务见 [插件市场](/plugins/?category=Tts)。

## 生词管理

内置生词本支持收藏词汇，以及本地备份与恢复。你也可以通过生词本插件连接其他词汇服务。

## 其他实用功能

软件还支持历史记录、二维码识别、全局热键和明暗主题切换。本地 HTTP 外部调用方式见 [集成调用](/docs/invoke/)。
