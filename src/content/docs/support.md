## 问题反馈

先查看 [常见问题](/docs/faq/)。如果仍然无法解决，可以在 [GitHub Issues](https://github.com/STranslate/STranslate/issues) 中搜索已有反馈，或提交新问题。

描述问题时，请提供软件版本、操作步骤、预期结果和实际结果。截图及错误信息能帮助定位问题；分享前请注意隐藏 API Key 等个人信息。

## 帮助改进文档

每篇文档底部都有「在 GitHub 上编辑」入口。欢迎修正错误、补充使用方法或改善表达，也欢迎 [提交插件](https://github.com/STranslate/STranslate-doc#提交插件)。

## 请作者喝杯阔落

如果 STranslate 对你有帮助，可以支持作者的持续开发。感谢每一位使用、分享和贡献的朋友。
